НАРЯДЫ — работает без интернета, сохраняет само
================================================

Что внутри: index.html (приложение), sw.js (работа без сети), manifest.webmanifest и две иконки.
Входа и паролей нет. Все данные хранятся на телефоне и сохраняются сразу после каждого нажатия.

ШАГ 1. Выложите папку в интернет (один раз, лучше с компьютера). Любой из вариантов:

  А) Netlify Drop (проще всего): откройте app.netlify.com/drop, перетащите в окно всю папку.
     Получите ссылку вида https://что-то.netlify.app

  Б) GitHub Pages: создайте репозиторий, загрузите в него все файлы,
     затем Settings -> Pages -> Deploy from a branch -> main / root.

  В) Cloudflare Pages: Workers & Pages -> Create -> Pages -> Upload assets.

ШАГ 2. На iPhone откройте ссылку в Safari (не в другом браузере) и дождитесь, пока страница загрузится.
       Нажмите «Поделиться» -> «На экран „Домой“» -> «Добавить».

ШАГ 3. Запускайте приложение с иконки на экране «Домой». Проверка: включите авиарежим и откройте иконку —
       приложение должно открыться, данные должны быть на месте.

ВАЖНО
- Интернет нужен только один раз, чтобы открыть ссылку и добавить иконку.
- Открывайте именно иконку с экрана «Домой»: обычная вкладка Safari может очищаться системой, а установленное приложение — нет.
- Если удалить иконку или стереть данные сайта, данные пропадут. Раз в месяц нажимайте
  «Настройки» (вкладка «Ставки») -> «Копия данных» -> «Показать копию» и сохраните текст в заметках.
- Перенос из прежнего приложения: там «Ставки» -> «Копия данных» -> «Показать копию», скопируйте текст,
  здесь «Ставки» -> «Копия данных» -> вставьте -> «Загрузить». Перенесутся наряды и ставки.
